## 对话结束前你必须做的事

**每次对话结束前，主动提示用户更新文档。** 根据本次对话内容，输出需要更新的文档的完整新版本供用户下载替换。

更新规则：

**项目启动文档** — 如果本次对话涉及：
- 技术方案有新决定（如选定了地图组件、部署平台）
- 当前阶段任务有进展（完成了某个模块）
- 产品需求有调整

**数据库启动文档** — 如果本次对话涉及：
- 完成了某部书的数据生产（在书目表里标记✅并填写条数）
- 数据字段或提取规范有调整

**决策日志** — 如果本次对话涉及：
- 做出了任何产品、数据、技术方面的决定
- 否定了某个方案
- 有新的待决定事项

## 重要约束

- 飞书App Secret是敏感信息，不能出现在任何代码文件或前端页面中，只能用环境变量
- 数据字段结构已定型，不要修改飞书表格字段名
- 单选字段的值必须严格匹配数据库启动文档中的合法值列表
- 有任何不确定的决策，先问用户确认，不要自行决定
