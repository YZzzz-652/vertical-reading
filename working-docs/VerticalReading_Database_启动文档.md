## 一、项目是什么 · 现状

一个"垂直穿透读书"的可视化工具，以时间、地点、人物类型为坐标轴，让用户看到不同作品里的人物在同一时空下的平行命运。当前 MVP 聚焦**时间维度**穿透。产品/技术细节见 `working-docs/VerticalReading_项目启动文档.md`。

**现状**：基线书目已全量写入飞书；**总量与逐本状态以 `working-docs/VerticalReading_书目清单.md` 为准**（本文档不另记数字，避免漂移）。扩库为下一阶段工作，任务跟踪在 `working-docs/VerticalReading_项目启动文档.md` 当前待办。

## 二、开工前必读（产数据前逐条过）⚠️

这一节是产数据最容易踩、且踩了往往无报错的硬规则与坑，开工前必须逐条过。逐字段规范见第三节。

1. **角色选取**：每部提取 3–5 个角色，主角全程追踪，配角选最重要的 2–3 个。
2. **密度控制（质量优先，不以条数为硬上限）**：严格只选两类事件——
   - 角色命运转折点（改变角色走向的决定性时刻：初遇、决裂、死亡、觉醒等）；
   - 情节起承转合节点（推动整体故事结构的关键事件：冲突爆发、高潮、结局等）。
   - **不选**：过程描述、状态延续、重复场景、细节补充。同一处境只选最具代表性的一条。
   - **密度限制**：同一角色同一年内最多 2 条；时间跨度短的书（单一事件/单日叙事）全书每角色不超过 3 条。
3. **单选/多选字段绝不用兜底值**：取值必须严格落在第三节合法值列表内，不自创新值，**绝不写「其他」**——不确定归哪一类的，单独摘出来人工确认。（历史教训：曾因混入「其他」导致数据偏差。）
4. **阶层标签只取 8 个合法值**（前端 CLASS_OPTIONS 白名单与之对齐）：不取白名单外的值，不确定的人工确认。确需新增阶层类别，须同步飞书合法值列表与前端 CLASS_OPTIONS（注意 AGENTS 硬约束：飞书合法值列表改动需谨慎）。
5. **经纬度负号必须是标准 ASCII `-`**，不能用特殊减号 `−`（U+2212）——飞书 API 会报 `NumberFieldConvFail`。西经地区（英国、美国、拉丁美洲等）坐标为负，是 Unicode 减号混入高发区。**生成后必须用脚本检测所有负数经纬度的负号是否为标准字符。**
6. **原文摘录译本**：俄国文学用人民文学出版社译本，英美 / 法国文学用译林出版社译本。
7. **输出格式**：CSV，UTF-8 编码，第一行为字段名表头。可一次处理多本书。你只需生成正确格式的 CSV，写入飞书由用户的工具处理，不需要写入逻辑。

## 三、字段与规范（生成时对照）

### 3.1 字段总览（20 个字段，CSV 固定顺序，不可更改）


| 2 | 书名 | 文本 | — |
| 3 | 作者 | 文本 | — |
| 4 | 国家地区 | 单选 | 俄国、英国、美国、法国、德语地区、拉丁美洲、中国、日本、南亚、中东与波斯、非洲、北欧、南欧、东欧（**无「其他」**；不确定的人工确认，见开工前必读 3） |
| 5 | 人物姓名 | 文本 | — |
| 6 | 阶层标签 | 单选 | 贵族、资产阶级、平民、底层、宗教人士、军人、知识分子、奴隶农奴（共 8 个，**无「其他」**；与前端 CLASS_OPTIONS 对齐，见开工前必读 4） |

| 8 | 细描标签 | 文本 | 人物身份的细致补充——阶层标签只有固定几档太粗，用一个**简短的身份词**做更细描述。例：贫困大学生、某人的妹妹、预审法官、庄园主之女、磨坊主、富商挚友 |
| 9 | 事件描述 | 文本 | 1–2 句话，说明人物在做什么 |

| 11 | 书中位置 | 单选 | 开头、中段、结尾 |
| 12 | 显示年份 | 数字 | 纯数字，用于时间轴排序 |

| 18 | 纬度 | 数字 | 纯数字；负号规范见开工前必读 5 |
| 19 | 地点类型 | 单选 | 真实、虚构映射、虚构无对应 |
| 20 | 事件类型 | 多选 | 事件极性标签，9 组 18 个，规则与合法值见 3.2 |

### 3.2 需要展开的字段细则

**事件类型（多选）**

- 飞书多选字段（每条事件可选多个，程序按多选读取），CSV 中为最末列。
- 每条事件至少打 1 个标签，建议 2 个；标签之间无顺序要求。
- 取值必须落在下方 9 组 18 个合法值内，不自创、不用兜底值。
- 新增标签必须**成对增加**（如新增「离别」必须同时新增「重逢」），不允许单独新增单极标签；每次追加需更新本表。

| 组 | 左极 | 右极 | 定位说明 |
|---|---|---|---|
| 1 | 死亡 | 新生 | 生命的终结与开始，包括人物的死亡、出生、重生，以及象征性的旧我消亡与新我诞生 |
| 2 | 离散 | 团聚 | 人物之间的分离与重逢，包括家庭离散、流亡别离，以及久别重逢、亲人团圆 |
| 3 | 背叛 | 忠诚 | 人物对他人、理想或立场的背弃与坚守，包括出卖同伴、变节投敌，以及誓死追随、不离不弃 |
| 4 | 堕落 | 救赎 | 人物道德或精神层面的下沉与向善，包括腐化堕落、自我毁灭，以及悔悟自新、被他人拯救 |
| 5 | 顿悟 | 迷茫 | 人物认知上的突然清醒与持续困惑，包括一瞬间的彻悟、看穿真相，以及对自我和世界的迷失与困顿 |
| 6 | 反抗 | 屈服 | 人物面对压迫或命运的抗争与妥协，包括起义、拒绝、出走，以及顺从、放弃、认命 |
| 7 | 相遇 | 决裂 | 人物关系的建立与断绝，包括初次相识、命运交汇，以及彻底决裂、关系破碎 |
| 8 | 萌芽 | 幻灭 | 爱情的萌生与破灭，包括一见钟情、情感升温，以及爱情幻灭、心死决绝 |
| 9 | 叩问 | 笃定 | 人物对存在意义的主动追寻与最终确立，包括对自我、信仰、人生目的的持续诘问，以及找到信仰或方向后的确定感 |

**时间类型（单选，三类处理规则）**

- **历史锚定**：有明确历史年份，直接用年份。
- **虚构映射**：虚构但有历史原型（如《红楼梦》映射清雍乾年间约 1730s，《百年孤独》映射 1820s–1950s）。显示年份用估算值，时间备注注明"约"。
- **创作年代**：刻意模糊无法定位（如卡夫卡），用作者写作年代，地点用作者所在城市。
