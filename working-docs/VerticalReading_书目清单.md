# Vertical Reading · 书目清单（数据生产进度）

> **职责**：记录数据生产的实际进度——哪些书已入库、各书状态与条数、ID 前缀、主要角色。这是**动态文档**：扩库时把新书逐部加进来（先标待办，产完改已完成、回填条数），不是一次写死的静态清单。
> **与数据库文档的分工**：`working-docs/VerticalReading_Database_启动文档.md` 管"**怎么产**"（字段、合法值、密度等规范）；本文档管"**产了哪些、产到哪了**"。
> **类型**：累积型（动态）。加新书时追加，不删历史。
> **读取时机**：数据扩充 / 生产时必读，加新书前查 ID 前缀与查重（见 AGENTS §5 路由表）。
