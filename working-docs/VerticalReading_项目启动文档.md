## 产品是什么

一个"垂直穿透读书"的文学可视化平台。打破书本边界，以时间、地点、人物类型为坐标轴，让用户用上帝视角看到不同作品里的人物在同一时空下的平行命运。

**核心体验**：拖动时间轴到 1860 年代，地图上同时亮起——郝思嘉在亚特兰大逃难、拉斯柯尔尼科夫在圣彼得堡街头游荡、贾宝玉在大观园读书。点击任意一点，展开人物的故事和原文。

**三条穿透维度（均已实现）**：① 时间穿透 ✅；② 地点穿透 ✅；③ 角色类型穿透 ✅。

当前阶段供个人使用，无需登录与权限系统。

### Turbopack 与 OneDrive 路径不兼容
- 问题：项目在 OneDrive 目录下，Turbopack 报 native bindings 错误无法启动。
- 解决：开发 `npm run dev`（dev 已固定 --webpack）；本地构建必须显式 `npx next build --webpack`，不要用 `npm run build`（build 未固定，会走 Turbopack 报错）。
- 记录日期：2026-04-26

### 天地图安全密钥开启会导致瓦片整批 403
- 问题：天地图控制台「安全密钥」开关开启时，浏览器端 Leaflet 的纯 ?tk= 瓦片请求无签名，被全部拒为 403（底图空白、wmts 请求全红）。
- 解决：浏览器端瓦片场景保持「安全密钥」关闭。
- 记录日期：2026-05-30

### Codex 无法访问 Claude 环境路径
- 问题：Claude 生成的文件在 `/mnt/user-data/outputs/`，Codex 本地运行无法访问。
- 解决：图片或文件素材需用户手动下载后放入项目 `public/` 目录，再由 Codex 引用。
- 记录日期：2026-05-10

### Codex 预览窗口与浏览器实际效果不一致
- 解决：验证效果以 localhost 浏览器为准，不以 Codex 预览窗口为准。
